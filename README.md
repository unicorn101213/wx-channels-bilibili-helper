# 视频号 · B站下载助手（免激活稳定版）

Chrome / Edge 扩展（Manifest V3，当前 1.2.3）。在网页版文件传输助手里处理两类转发：

- **微信视频号**：解密后，大约 20MB 以内的视频会作为可播放的 `.mp4` 发回对话框。
- **B 站**：回发一条可点击的 MP4 直链，不把视频再上传一遍。

抖音不解析，分享文字保持原样。默认不往电脑「下载」文件夹里存文件。

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`，打开「开发者模式」。
2. 「加载已解压的扩展程序」，选中本目录。
3. 改完代码后，在扩展卡片上点重新加载。

## 使用

1. 用浏览器打开并登录 [文件传输助手](https://filehelper.weixin.qq.com/)。这个标签页要一直开着，并且同一微信不要同时在另一台浏览器里登录它，后登录的会把先登录的顶掉。
2. 把视频号或 B 站内容转发到自己的文件传输助手。
3. 视频号会先提示正在解密。不大的文件会发回 `.mp4`。B 站直接回一条直链。
4. **超过大约 20MB** 时，网页版文件传输助手发不出去。打开插件弹窗，在「最近捕获的视频记录」里点 **解密下载**，浏览器会直接保存 mp4。这条记录里已经带有地址和解密所需信息。
5. 「同时保存到电脑本地下载目录」默认关闭。打开后，小文件也会额外存一份到本机。

网页版微信登录通常几天就会过期，过期后重新扫码。不要用非官方微信协议保活。

## 隐私与安全

公开前已核对仓库内容：没有微信登录态、Cookie、口令、个人聊天记录或本机捕获历史。这些都只留在你自己的浏览器里。

使用时仍会发生下面这些事：

- 视频号转发会被读出 `objectId` 和 `objectNonceId`，并发送到第三方解析服务 `https://vbe5k5l2ij.gzg.sealos.run`（`/xbd_ext_cloudDecrypt`，失败时再试 `/xbd_parseVideo`）。这个服务不是本仓库运营的。解密本身在你的浏览器里完成，不会把整段视频上传到该服务。
- B 站只请求哔哩哔哩公开接口，用来换取 MP4 直链。
- 最近捕获的标题、地址和解析记录保存在本机 `chrome.storage.local`，可在弹窗里清空。
- 扩展申请了全部网址的访问权限，用来在文件传输助手页面接收消息，以及从视频 CDN 拉取文件。

不要把浏览器用户目录、微信网页登录数据或带有个人捕获记录的配置文件提交到这个仓库。

## 云端浏览器

同一微信的网页版文件传输助手只适合挂在一处。放到 Linux 上的 Chrome 时，建议 `--shm-size=1gb`，并关掉「内存节省模式」，只让文件传输助手留在前台。机房 IP 上微信可能要求反复扫码。

## 第三方代码

`ajaxhook.min.js` 来自开源库 [ajaxhook](https://github.com/wendux/ajax-hook)，用于监听页面里的消息同步请求。

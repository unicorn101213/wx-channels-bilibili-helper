# 视频号 · B站下载助手（免激活稳定版）

Chrome / Edge 扩展（Manifest V3，当前 1.3.0）。在网页版文件传输助手里处理三类转发：

- **微信视频号**：优先调用本机 `127.0.0.1:2022`（配合电脑版微信 `4.1.13` 本机直抓服务）换取真实地址与密钥，未启动本机服务时自动回退云端接口。20MB 以内的视频作为可播放的 `.mp4` 直接发回微信对话框；超过 20MB 的视频自动由浏览器直接保存完整 `.mp4` 到电脑下载目录（0 弹窗）。
- **B 站（哔哩哔哩）**：回发一条可点击的 MP4 直链，不把视频再上传一遍。
- **抖音（Douyin）**：通过本机 `127.0.0.1:2022` 服务走移动端协议无感解析（**不开新标签页、0 滑块验证、0 登录弹窗**），直接回发无水印 MP4 直链。

默认不往电脑「下载」文件夹里额外存小文件和封面图，避免浏览器弹出“允许下载多个文件”确认框。

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`，打开「开发者模式」。
2. 「加载已解压的扩展程序」，选中本目录。
3. 改完代码后，在扩展卡片上点重新加载。

## 两种使用方式（可同时使用）

### 方式一：电脑版微信 `4.1.13` 点开视频即下（100% 本地、完全不靠外部服务器）

1. 安装微信 Windows `4.1.13` 并关闭自动更新。
2. 启动本机直抓服务（默认监听 `http://127.0.0.1:2022` 与 `127.0.0.1:2023`）。
3. 在电脑版微信里点开视频号卡片的第 1 秒，播放器内即出现「下载」按钮，点击即可把解密后的原画 `.mp4` 直接存进电脑 `Downloads` 目录，无需把视频看完。
4. 同时也可打开 `http://127.0.0.1:2022` 本地控制台，粘贴抖音 / B站 / 视频号链接直接下载。

### 方式二：网页版文件传输助手自动回传（三合一）

1. 用浏览器打开并登录 [文件传输助手](https://filehelper.weixin.qq.com/)，保持该标签页打开。
2. 把 **视频号**、**B 站** 或 **抖音分享口令** 转发到自己的文件传输助手：
   - **视频号**：20MB 以内直接发回可播放的 `.mp4` 到对话框；超过 20MB 直接由浏览器自动保存 `.mp4` 到本地下载目录。随时可在插件弹窗「最近捕获的视频记录」里点 **解密下载**。
   - **B 站 / 抖音**：直接在对话框回发一条可点击下载的无水印 MP4 直链。

## 隐私与安全

仓库内不包含任何微信登录态、Cookie、口令、个人聊天记录或本机捕获历史。

- 若本机启动了 `127.0.0.1:2022` 直抓服务，视频号详情与抖音无水印直链均在本机完成解析。
- 若未启动本机直抓服务，视频号卡片中的 `objectId` 和 `objectNonceId` 会回退发送至第三方解析服务 `https://vbe5k5l2ij.gzg.sealos.run` 换取地址和密钥；视频流解密始终在本地浏览器内通过 ISAAC-64 完成。
- 最近捕获记录保存在本机 `chrome.storage.local`，可在弹窗里随时清空。

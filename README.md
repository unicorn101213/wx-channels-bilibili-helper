# 视频号 · B站 · 抖音下载

在自己的电脑上下载微信视频号、哔哩哔哩和抖音。三个站点都能下，操作不一样：视频号在电脑微信里点一下；B 站和抖音把分享文字粘进本机网页。

文件都进当前 Windows 用户的「下载」文件夹。不经过网页微信，也不再把视频传回文件传输助手。

## 和以前的浏览器插件有什么不同

以前的「视频号 · B站下载助手」要装在浏览器里，配合网页版文件传输助手使用。视频号的真实地址还要发给第三方解析服务，解密后的文件再传回网页微信，超过大约 20MB 就传不回去。

现在这套程序不走那条路：

- 视频号：电脑微信自己的播放页上出现下载按钮，文件直接存在这台电脑。
- B 站和抖音：本机网页粘贴分享文字，文件直接存在这台电脑。
- 不再需要网页版文件传输助手，也不再调用那个第三方解析服务。

旧的浏览器插件和更早的备份都在本目录的 `参考` 文件夹里，只留作对照，日常不要用。

## 怎么下载

### 微信视频号

1. 电脑微信保持 **4.1.13**，自动更新保持关闭。更新到更高版本后，播放器不再是网页，下载按钮不会出现。
2. 在微信里点开要下的视频，不用看完。
3. 播放器右下角出现下载图标后点它。
4. MP4 出现在「下载」文件夹。

### 哔哩哔哩、抖音视频、抖音图文

1. 打开 http://127.0.0.1:2025
2. 在微信里复制整段分享文字，粘进去，回车。
3. 视频存成一个 MP4。抖音图文不是视频，会存成一个文件夹，里面是全部图片。

页面左侧「已下载」列出本工具生成的文件。下载完成后可以播放、打开文件夹，或删除。删除会同时去掉「下载」文件夹里的那个文件或图片文件夹。

## 这是几个程序

同一个文件夹里有两个程序，开机时一起启动。没有打成一个安装包。

| 程序 | 端口 | 负责什么 |
| --- | --- | --- |
| `wx_video_download.exe` | 2022、2023 | 微信视频号。2022 是本机接口，2023 只转发视频号页面，用来在播放器上加下载按钮 |
| `simple-ui.js` | 2025 | 你打开的下载台。B 站自己下载；抖音普通视频先问 2022 要地址，再自己保存；抖音图文由 2025 自己取图片 |

关系可以看成：

```
开机
  └─ boot.js
       ├─ 2025 没人听 → 启动下载台（B 站、抖音、抖音图文）
       └─ 2022 没人听 → 启动视频号程序（同时打开 2023）

电脑微信里点开视频号
  └─ 只有视频号的两个域名转到 2023
       └─ 播放器右下角出现下载 → MP4 进「下载」

在 2025 粘贴分享文字
  ├─ B 站       → 下载台自己下载
  ├─ 抖音视频   → 下载台问 2022 要地址，再自己下载
  └─ 抖音图文   → 下载台自己把图片存进一个文件夹
```

2022 停了，视频号下载按钮和抖音普通视频会受影响；B 站和抖音图文仍由下载台处理。2025 停了，只是打不开下载台，视频号右下角的按钮还在。

视频号程序来自 [wx_channels_download](https://github.com/ltaoo/wx_channels_download) v260907，本目录带有它的可执行文件和 `LICENSE`。请勿把它拿去出售。

## 开机启动

登录 Windows 后会自动启动，不用先打开网页。启动项执行 `boot.js`：2025 或 2022 已经有程序在听时，不会再开第二个。

手动再装一次开机启动：双击 `安装开机启动.bat`。

这次要用时：双击 `启动本机直抓服务.bat`，或直接打开 http://127.0.0.1:2025 。

## 文件名

都在「下载」文件夹：

- B 站：`[B站]_标题.mp4`
- 抖音视频：`[抖音]_标题.mp4`
- 抖音图文：`[抖音图文]_标题\`，里面是 `01.webp`、`02.webp` 这样的图片

## 使用时注意

- 电脑微信停在 4.1.13，不要更新。
- `config.yaml` 里的 `proxy.system` 保持 `false`。这个程序不接管 Windows 系统代理。系统代理仍交给你原来的代理软件。代理软件里只需要把 `channels.weixin.qq.com` 和 `res.wx.qq.com` 转到 `127.0.0.1:2023`；2022 没开时，这两站应能退回直连，视频号页面仍能看，只是没有下载按钮。
- 抖音图文依赖本机 Chrome 里已经登录过的抖音。如果某天图文取不到图片，用 Chrome 打开抖音网页登录一次再试。普通抖音视频和 B 站不需要这一步。
- 文件正在播放时可能删不掉，先关掉播放窗口再点删除。
- `参考` 文件夹、运行时数据库和缓存不参与日常使用，也不需要提交到仓库。

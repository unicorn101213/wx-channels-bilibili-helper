# 视频号 · B站下载助手（免激活稳定版）

个人使用的 Chrome / Edge 扩展（Manifest V3）。只处理两件事：

- **微信视频号**：在网页版文件传输助手里收到卡片后，解密并回传一个可播放的 `.mp4` 文件气泡。
- **B 站**：回发一条可点击的 MP4 直链，不把视频再上传一遍。

抖音不解析，分享文字保持原样。默认不保存到本机「下载」文件夹，避免浏览器弹出「允许多个下载」。

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`，打开「开发者模式」。
2. 「加载已解压的扩展程序」，选中本目录。
3. 若之前装过旧目录里的版本，先移除旧项，再从本目录重新加载。改完代码后点扩展卡片上的重新加载。

## 使用

1. 用浏览器打开并登录 [文件传输助手](https://filehelper.weixin.qq.com/)，这个标签页要一直开着。
2. 把视频号或 B 站内容转发到自己的文件传输助手。
3. 视频号会先出现状态说明，解密完成后回传 `.mp4`。B 站直接回一条直链。
4. 弹窗里「保存到本地磁盘」默认关闭。只有打开后才会下载到本机。

网页版微信登录通常几天就会过期，过期后重新扫码即可。不要用非官方微信协议保活。

## 云端浏览器

若放到 Linux 上的 Chrome，解密和回传文件需要更大的共享内存，建议 `--shm-size=1gb`，并关掉 Chrome 的「内存节省模式」，只让文件传输助手保持在前台。
